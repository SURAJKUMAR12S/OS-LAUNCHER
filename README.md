About SO LAUNCHER

SO LAUNCHER is an Android launcher project designed to let users play Minecraft: Java Edition on Android devices.

SO LAUNCHER is based on the MojoLauncher project, which itself is based on PojavLauncher.

The project aims to provide an Android-friendly way to launch Minecraft Java Edition, manage game versions, and enjoy Minecraft on mobile devices.

Features

SO LAUNCHER inherits the launcher functionality of its upstream project, including:

- Support for many Minecraft Java Edition versions.
- Minecraft version selection.
- Support for Forge and Fabric mod loaders.
- Support for ".jar"-based installers.
- Minecraft mod support.
- Game profile and instance management.
- Android-friendly launcher interface.
- A dedicated YouTube Channel button for the SO LAUNCHER community.

Some features and compatibility depend on the upstream project and device configuration.

Building

To build the Android launcher from source:

./gradlew :app_mojo:assembleDebug

The build process downloads the required components automatically.
